# 🏰 Оборона Базы (Tower Defense) — многопользовательская 2D игра

Кооперативная браузерная игра на 6 человек. Игроки вместе защищают командный
центр в центре карты от волн мобов, строя стены, башни, генераторы и казармы.

## Технологии

- **Сервер**: Node.js + WebSocket (`ws`), реальное время, 25 обновлений/с
- **Клиент**: HTML + CSS + JavaScript, рендер на Canvas 2D (без фреймворков)
- **Оптимизация**: пространственное хеширование, отрисовка только видимых объектов

## Возможности

- Комнаты до 6 игроков (создание/присоединение по коду)
- Свободное перемещение WASD
- Ресурсы: дерево 🪵, камень 🪨, еда 🍗
- Постройки:
  - 🧱 **Стена** — танкует урон, блокирует проход
  - 🗼 **Башня** — автоматически атакует мобов (3 ур. — зенитка по летающим)
  - ⚙️ **Генератор** — пассивно добывает ресурсы
  - 🏰 **Казармы** — нанимает юнитов-охранников
- Все постройки улучшаются (до 5 уровня)
- Прокачка персонажа: скорость/урон/здоровье за еду
- Волны мобов: 🚶 **пехота**, 🏃 **бегун**, 🐢 **танк**, 🪽 **летающий**
- Чат, миникарта, тултипы при наведении, очки/опыт за убийства

## Запуск локально

1. Установи [Node.js](https://nodejs.org/) (18+).
2. Установи зависимости:
   ```bash
   cd tower-defense
   npm install
   ```
3. Запусти сервер:
   ```bash
   npm start
   # или: node server.js
   ```
4. Открой в браузере: `http://localhost:8080`
   (сеть: `http://<IP-компьютера>:8080`, чтобы играли с других устройств)

## Управление

| Действие | Клавиши |
|----------|---------|
| Движение | `WASD` (также `ЦФЫВ` для раскладки) |
| Атака по мобу | клик `ЛКМ` по врагу |
| Строительство | клик по кнопке внизу → клик по месту на карте |
| Отмена стройки | `Esc` |
| Чат | `T` |

## Как играть командой

1. Первый игрок создаёт комнату (вводит код) и нажимает «Создать/Присоединиться».
2. Отправляет код друзьям — они вводят его и присоединяются (до 6 человек).
3. Все нажимают «✅ Готов» — бой начнётся автоматически.
4. Стройте стены и башни вокруг базы, ставьте генераторы для ресурсов,
   казармы — для юнитов-защитников.
5. Между волнами есть пауза на строительство (таймер обратного отсчёта).

## Деплой

Проект готов к деплою на любом Node-хостинге (Railway, Render, Fly.io и т.п.):

- `Procfile`: `web: node server.js`
- Порт берётся из `PORT` переменной окружения (по умолчанию 8080)
